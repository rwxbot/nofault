# v0.9.0 架构：微服务全家桶

## 一句话

前八个版本交付的是**能力**；这一版负责把它们**接起来**，
并补上微服务必需、但单进程时代可以糊弄过去的四样东西。

## 一、为什么这四样不能省

| 缺了它 | 后果 | 什么时候被发现 |
| --- | --- | --- |
| 分布式 ID | 多实例各有自增计数器，合表必撞 | 上线当天 |
| 分布式锁 | 定时任务在 N 个实例上跑 N 遍；用户连点两次被扣两次 | 上线一周后 |
| 事件总线 | 模块之间直接互相 import，最后变成一坨 | 三个月后没人敢改 |
| 一键装配 | 五十行样板代码，顺序错了就有微妙问题 | 偶发生><生产故障时 |
